# CWE-1321: Prototype Pollution

**Category**: Injection
**Severity**: High

User-controlled keys or values modify `Object.prototype`, affecting all objects
in the application and potentially enabling property injection, denial of
service, or remote code execution.

## The Problem

JavaScript objects inherit properties from `Object.prototype`. If an attacker
can set arbitrary keys on an object (via `__proto__`, `constructor`, or
`prototype`), those properties propagate to all objects. This can override
security checks, inject default values, or trigger code execution in frameworks
that inspect object properties.

## Defense

**Filter dangerous keys from user input. Use `Map` for user-keyed data. Use
`Object.create(null)` for lookup tables.**

### TypeScript

```typescript
// WRONG: spreading user input into an object
const config = { ...defaults, ...JSON.parse(userInput) }
// Attacker sends: {"__proto__": {"isAdmin": true}}

// WRONG: recursive merge without key filtering
function merge(target: any, source: any) {
  for (const key in source) {
    target[key] = source[key] // pollutes prototype if key is "__proto__"
  }
}

// RIGHT: filter dangerous keys before merging
const BLOCKED_KEYS = new Set(["__proto__", "constructor", "prototype"])

function safeMerge<T extends Record<string, unknown>>(
  target: T,
  source: Record<string, unknown>,
): T {
  for (const key of Object.keys(source)) {
    if (BLOCKED_KEYS.has(key)) continue
    target[key as keyof T] = source[key] as T[keyof T]
  }
  return target
}

// RIGHT: use Map for user-keyed data — no prototype chain
const userPrefs = new Map<string, string>()
userPrefs.set(userKey, userValue) // safe regardless of key value

// RIGHT: use null-prototype objects for lookup tables
const lookup = Object.create(null) as Record<string, string>
lookup[userKey] = userValue // no prototype to pollute
```

## Key Rules

- Filter `__proto__`, `constructor`, and `prototype` keys from all user-supplied
  objects
- Use `Map` instead of plain objects for user-keyed data
- Use `Object.create(null)` for lookup tables that accept dynamic keys
- Validate JSON input structure with a schema (e.g., Zod, AJV) before spreading
  into objects
- Freeze prototypes in security-sensitive contexts:
  `Object.freeze(Object.prototype)` (last resort; can break dependencies)
