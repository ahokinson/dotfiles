# CWE-611: XML External Entity (XXE)

**Category**: Injection
**Severity**: High

XML parsers configured to resolve external entities allow attackers to read
local files, perform SSRF, or cause denial of service.

## The Problem

XML supports external entity declarations that reference URLs or file paths.
When a parser processes untrusted XML with external entity resolution enabled,
an attacker can read arbitrary files (`file:///etc/passwd`), make server-side
requests to internal services, or trigger billion-laughs DoS attacks.

## Defense

**Disable external entity resolution and DTD processing in every XML parser.**

### Go

```go
// Go's encoding/xml is safe by default — it does not support external entities or DTDs.
// No special configuration needed.
var data MyStruct
err := xml.Unmarshal(input, &data)

// CAUTION: if using a third-party XML library (e.g., libxml2 bindings),
// verify that external entities are disabled — Go's safety guarantee
// applies only to encoding/xml.
```

Go's `encoding/xml` is safe by default. It does not process DTDs or external
entities. This is the correct parser to use for untrusted XML.

### Python

```python
# WRONG: default xml.etree allows entity expansion
import xml.etree.ElementTree as ET
tree = ET.parse(untrusted_file)

# RIGHT: use defusedxml
import defusedxml.ElementTree as ET
tree = ET.parse(untrusted_file)

# defusedxml blocks: external entities, DTD retrieval, entity expansion bombs
# Install: pip install defusedxml
```

### TypeScript

```typescript
// WRONG: default libxmljs or fast-xml-parser with entities enabled
import { parseXml } from "libxmljs"
const doc = parseXml(untrustedInput)

// RIGHT: disable external entities and DTD
import { XMLParser } from "fast-xml-parser"
const parser = new XMLParser({
  processEntities: false,
  htmlEntities: false,
})
const result = parser.parse(untrustedInput)

// Or: convert to JSON at the boundary and avoid XML parsing entirely
```

## Key Rules

- Disable DTD processing and external entity resolution in every XML parser
  configuration
- Go `encoding/xml` is safe by default; no action needed for stdlib
- Python: always use `defusedxml` instead of `xml.etree`, `xml.sax`, or `lxml`
  with defaults
- If possible, use JSON instead of XML for data exchange; it has no equivalent
  vulnerability class
- For XSLT and XPath: apply the same restrictions: disable document() functions
  and external references
- Test with an XXE payload to confirm your parser configuration is effective
